## 4. 評価の目安

- ○ 有効: 承認・運用・有効性・完了確認が証憑で確認できる。
- △ 一部不備: 運用実体はあるが記録に不備。事例④⑥は現物が出てくればこれに該当する見込み。
- × 不備: 現物が出てこない／同種が再発。事例①（支払い）は再発が明確。
- － 対応中: 完了予定日が未到来（#30は2027/1/31）。

## 5. 改善指示書（◆）で想定する指摘事項（案）

1. 支払い統制: AIチェック・自動検知の検出結果を承認者が判断した記録として残す。月中の資産照合の確実な実施。
2. 財務制限条項の一覧管理と、資金繰り確認・取締役会報告への組み込み。
3. 事後稟議・契約更新漏れの全社件数を事務局が集計し、R&C委員会等で定点報告。
4. 「有効性」は完了から一定期間後の再発有無で記入する運用に改め、全社ルール化（事務局）。レベル3の役員会確認の運用再開。
5. 期限超過7件・承認日なし5件・対策未記載1件のクローズと、完了日・証憑リンクの台帳記録。
