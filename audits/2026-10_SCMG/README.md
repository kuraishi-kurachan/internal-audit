## 4. 評価の目安（監査プログラム 02 に準拠）

- ○ 有効: 承認・運用・有効性・完了確認が証憑で確認できる。
- △ 一部不備: 運用実体はあるが記録に不備（承認日未記入など）。SCMGは多くがこれに該当する見込み。
- × 不備: 現物が出てこない／同種が再発している（事例①②は該当する可能性が高い）。
- － 対応中: 完了予定日が未到来。

## 5. 改善指示書（◆）で想定する指摘事項（案）

1. レベル3の恒久対応策・承認日・完了予定日の必須化と、未記載6件の遡及整備。
2. 外部・委託先起因でも「対応不要」の判断と承認を台帳に残す運用。
3. 委託先起因インシデントは委託先の手順改訂・報告（業務基本契約書第21条）を恒久対応の証憑とする。
4. 出荷締め漏れの自動検知（人の確認からシステム検知へ）をPDGと検討。
5. 未クローズ案件の週次確認の場の設置（GRGの週次DivリーダーMTGと同様）。
