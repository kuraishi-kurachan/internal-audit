# 第13期 内部監査フレームワーク（業務起因インシデント 恒久対応策の運用監査）

対象: 2027年6月期（2026年7月〜2027年6月） / 内部監査担当

本リポジトリは、第13期内部監査計画の**特別項目「インシデントの恒久対応策の運用状況の確認」**を、
現場に過度な負担をかけず、実効性と納得感をもって運用するための監査プログラムと支援の仕組みを整理したものです。

## 背景（既存の枠組み）

- 会社: 従業員約100名のベンチャー（グロース上場・airCloset）
- 内部監査計画: 部門（グループ単位）へのヒアリング＋固定設問による年次監査
- 監査サイクル: `●監査実施通知 → ★監査実施・報告書提出 → ◆改善指示書 → △改善実施計画書受取 → ○改善状況確認書受取`
- インシデント管理: 全社インシデント管理シートで発生〜恒久対応まで管理。レベルに応じ承認者が決定される
  - レベル3: 記入必須／承認 = グループ長 → 社長
  - レベル2: 記入必須／承認 = グループ長
  - レベル1: 記入不要／承認 = 不要

## 解こうとしている課題

1. 恒久対応策が**必要な承認を受けていない**（承認形跡がない）
2. 恒久対応策が**実際に運用されているか不明確**
3. 結果として**同種インシデントが再発**する

→ これらは「制度設計」ではなく「制度の**運用**」が特定の統制ポイントで途切れていることが原因。
　本フレームワークは、その統制ポイントを監査対象として明確に定義し、証憑で裏取りする。

## 設計思想（3つの原則）

- **実効性**: ヒアリング（認識確認）だけで終わらせず、少数サンプルの「証憑」で裏取りする。
- **低負担**: 現場に新規資料を作らせない。監査人が台帳から機械的に論点を抽出し、現物を1点見せてもらうだけにする。
- **納得感**: 「粗探し」でなく、改善サイクル（指示書→計画書→確認書）で一緒に穴を塞ぐ伴走型にする。抽出基準を透明化する。
