# 改善サイクル様式（指示書 / 実施計画書 / 状況確認書）

第13期計画の改善サイクル `◆改善指示書 → △改善実施計画書 → ○改善状況確認書` に対応するひな型。
発見事項を「言いっぱなし」にせず、期限・責任者付きで是正完了まで追跡するための3点セット。

---

## 様式A: 改善指示書（◆ 監査人 → 被監査部門）

| 項目 | 記入 |
| --- | --- |
| 発行番号 / 発行日 | |
| 宛先（部門 / 部門長） | |
| 関連インシデント（No / ユニークID） | |
| 発見事項（事実） | 例: Lv3恒久対応策に承認日の記録がない（3件） |
| 統制ギャップ区分 | G1承認 / G2実装 / G3有効性 / G4完了確認 |
| リスク・影響 | 例: 未承認の対策が運用され、再発・顧客影響が拡大しうる |
| 改善要請事項 | 例: 承認記録の遡及整備と、以後の承認必須運用 |
| 回答期限（改善実施計画書の提出期限） | |

---

## 様式B: 改善実施計画書（△ 被監査部門 → 監査人）

| 項目 | 記入 |
| --- | --- |
| 指示書番号 | |
| 根本原因（なぜ発生したか） | |
| 是正措置（具体策） | |
| 対策の種別 | 構造的対策（システム/自動化/権限分離） / 運用的対策（手順・記録） / 人的対策（教育・注意喚起） |
| 責任者 / 完了予定日 | |
| 再発防止の考え方 | 例: 人依存を排し、承認欄を必須化しシステムでガード |

> 監査人チェック: 対策が**人依存の対策のみ**に留まっていないか。留まっている場合は構造的対策の追加を求める。

---

## 様式C: 改善状況確認書（○ 監査人が確認しクローズ）

| 項目 | 記入 |
| --- | --- |
| 指示書番号 / 計画書受領日 | |
| 是正完了日 | |
| 確認した証憑 | 例: 承認欄の入力ルール化、条件付き書式の設定、改訂手順書 |
| 有効性の確認（G3） | 一定期間後に同種再発がないかを再確認した結果 |
| 判定 | 完了クローズ / 一部未完（継続フォロー） / 未対応（再指示） |
| 監査人 / 確認日 | |

> G3（有効性）は是正直後には判定できないため、**完了から一定期間後に再発有無を再確認**してから最終クローズする。
